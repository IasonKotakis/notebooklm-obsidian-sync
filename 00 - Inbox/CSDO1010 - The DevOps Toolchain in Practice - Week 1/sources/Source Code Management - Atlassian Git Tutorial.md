## Core Content
[[Source Code Management]] (SCM) is the practice of tracking and managing changes to software code over time. It provides a complete history of code changes, enables collaboration across development teams, and is a foundational practice in modern [[DevOps]] workflows. [[Git]] is the most widely used SCM tool, offering distributed version control capabilities.

## Key Points
- SCM enables multiple developers to work on the same codebase simultaneously without overwriting each other's work, using features like [[branching and merging]]
- A [[version control system]] maintains a full history of all changes, allowing teams to revert to previous states and audit who changed what and when
- SCM supports [[continuous integration]] and [[continuous delivery]] pipelines by providing a single source of truth for source code
- [[Distributed version control]] (as used in Git) means every developer has a full local copy of the repository, improving speed and resilience compared to centralised systems
- Best practices include committing small, frequent changes with clear messages, using [[feature branches]], and conducting [[code reviews]] via pull requests
