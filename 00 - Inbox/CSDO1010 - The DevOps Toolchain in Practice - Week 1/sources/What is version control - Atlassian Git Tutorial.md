## Core Content
[[Version control]] (also known as source control) is the practice of tracking and managing changes to software code over time. It allows developers to record the history of changes, revert to previous states, and collaborate without overwriting each other's work. Version control systems ([[VCS]]) are a foundational tool in modern [[software development]] and [[DevOps]] practices.

## Key Points
- A [[Version Control System]] keeps a complete history of every modification to a codebase, enabling rollback to any earlier state if bugs or issues are introduced.
- VCS supports parallel development through [[branching and merging]], allowing teams to work on features or fixes in isolation before integrating changes.
- [[Distributed Version Control Systems]] (DVCS), such as [[Git]], give every developer a full local copy of the repository, improving speed and resilience.
- Version control improves team collaboration by providing tools to resolve [[merge conflicts]] and review changes before they are accepted into the main codebase.
- VCS creates an auditable trail of who changed what and why, which is essential for [[code review]], compliance, and debugging.
