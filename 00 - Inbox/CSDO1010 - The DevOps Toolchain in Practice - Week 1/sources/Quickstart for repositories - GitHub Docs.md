## Core Content
This GitHub Docs quickstart guide walks through the essential steps for creating and managing a [[GitHub repository]], including setup, configuration, and collaboration features. It covers the full lifecycle of a repository from creation to settings management, branching strategies, and access control.

## Key Points
- A [[GitHub repository]] can be created from scratch, from a template, or by duplicating/cloning an existing one.
- [[README files]], licences, and topics help document and classify repositories for discoverability.
- [[Branch protection rules]] and rulesets enforce workflow policies such as required reviews before merging.
- [[Pull requests]] support multiple merge methods (merge commit, squash, rebase) and can be configured for auto-merge and automatic branch deletion.
- [[Collaborator permissions]] can be managed at the repository level, controlling who can read, write, or administer the repo.
