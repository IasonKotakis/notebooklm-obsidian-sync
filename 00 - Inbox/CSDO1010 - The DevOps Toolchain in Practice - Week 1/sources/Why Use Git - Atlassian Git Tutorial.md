## Core Content
[[Git]] is the world's most widely used [[version control system]], adopted by the vast majority of developers due to its performance, flexibility, and security. Unlike older centralised systems, Git uses a [[distributed version control]] model where every developer has a full local copy of the repository history. This makes Git ideal for both individual developers and large enterprise teams working within [[DevOps]] and [[Agile]] workflows.

## Key Points
- **Performance**: Git's core operations (commits, branches, merges) are optimised for speed and operate locally, making it faster than centralised [[version control systems]].
- **Distributed architecture**: Every developer's working copy is a full repository backup, reducing single points of failure compared to [[centralised version control]] (e.g. SVN).
- **Branching and merging**: Git's lightweight [[branching]] model enables developers to create isolated feature branches, supporting workflows like [[feature branch workflow]] and [[Gitflow]].
- **Security**: Git uses [[SHA-1 cryptographic hashing]] to track all content and changes, ensuring the integrity of code history against accidental or malicious tampering.
- **Wide adoption**: Git's dominance means extensive tooling support, community resources, and integration with platforms like [[Bitbucket]], [[GitHub]], and CI/CD pipelines.
